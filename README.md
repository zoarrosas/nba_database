# nba_database
# 🏀 NBA Database - Proyecto de Fundamentos de Bases de Datos

¡Bienvenido! Este proyecto es una base de datos diseñada para almacenar, gestionar y analizar estadísticas, equipos y jugadores de la NBA. Fue desarrollado como parte de la materia de **Fundamentos de Bases de Datos**.

---

## 🚀 Descripción del Proyecto
El objetivo principal es modelar la compleja estructura de la NBA. Permite registrar desde la información básica de las franquicias hasta el rendimiento detallado de los jugadores en cada partido, facilitando consultas avanzadas de estadísticas.

## 📊 Arquitectura y Modelo
*   **Motor de Base de Datos utilizado:** (Ej. MySQL, PostgreSQL, SQL Server)
*   **Componentes principales:**
    *   `Equipos`: Registro de conferencias, divisiones y estadios.
    *   `Jugadores`: Datos personales, posiciones y contratos.
    *   `Partidos`: Resultados, fechas y estadísticas de juego.

> 📝 **Nota:** En este repositorio encontrarás los scripts de creación de tablas (`.sql`), diagramas entidad-relación (DER) y algunas de las consultas (queries) principales solicitadas en clase.

## 🛠️ Cómo ejecutar el proyecto
1. Descarga o clona este repositorio.
2. Abre tu gestor de bases de datos (ej. Workbench, pgAdmin).
3. Importa y ejecuta el archivo `database_setup.sql` (o el nombre de tu script) para crear las tablas.
4. ¡Listo! Ya puedes empezar a realizar consultas.
